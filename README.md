# Філобот

Telegram-бот, який перетворює коротке повідомлення (напр. "привіт") на довгу,
псевдофілософську/рофляну версію.

## 1. Створи бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather) в Telegram.
2. Команда `/newbot`, дай назву і username (має закінчуватись на `bot`).
3. BotFather дасть токен — це `TELEGRAM_BOT_TOKEN`.

## 2. Візьми Anthropic API ключ

Зареєструйся на https://console.anthropic.com, створи ключ — це `ANTHROPIC_API_KEY`.
(Платний за використання, але для рофлу з друзями витрати мізерні — копійки за повідомлення.)

## 3. Встанови залежності

```bash
pip install aiogram anthropic
```

## 4. Запусти бота

```bash
export TELEGRAM_BOT_TOKEN="токен_від_BotFather"
export ANTHROPIC_API_KEY="твій_ключ"
python bot.py
```

## 5. Як користуватись

- **В приваті з ботом**: просто пиши будь-що — він одразу відповідає роздутою версією.
- **В груповому чаті**: згадай бота `@ім'я_бота привіт`, або команда `/rofl привіт`,
  або просто відповідай (reply) на повідомлення бота.

## Налаштування стилю

Стиль переписування задається в `SYSTEM_PROMPT` на початку `bot.py`.
Можеш змінити його, наприклад:
- зробити ще абсурднішим
- додати конкретні меми/фрази, які часто використовуєш з друзями
- зробити коротшим (зараз 3-6 речень)

## Важливо

- Бот має бути постійно запущений (на твоєму ПК, або на безкоштовному сервері типу Render/Railway),
  інакше він offline і не відповідає.
- Щоб бот бачив повідомлення в групі, в BotFather вимкни privacy mode:
  `/setprivacy` → вибери бота → `Disable`.
